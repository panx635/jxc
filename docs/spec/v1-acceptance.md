## §2 角色、权限与配置（6 条）

**AC-§2-1（P0）** 角色只有两个值，且至少保留一个启用的管理员
- Given 系统里有管理员 A、店员 B
- When 试图新建「仓管」角色，或停用 A
- Then 角色选择只有管理员 / 店员；停用 A 被拒绝，提示「至少保留一个启用的管理员」

**AC-§2-2（P0）** 店员菜单与动作边界
- Given 店员 B 登录
- When 打开菜单并尝试进入采购、商品档案、价格表、系统设置、账号、期初、导入、付款
- Then 这些入口都不出现；B 仍能开销售单 / 报价单、改单、作废（必填原因）、收款、查欠款、查库存数量

**AC-§2-3（P0）** 看成本开关即时生效，且过滤覆盖 API 与导出
- Given 店员 B 的 can_view_cost = false，已登录
- When 管理员打开开关并保存，B 不重新登录就打开库存查询并导出
- Then B 立即看到参考进价、结存金额；关掉后立即看不到；导出的 xlsx 同样按开关过滤

**AC-§2-4（P0）** 改价二次确认与今日让价
- Given 店员 B 开销售单，某行解析价 10 元
- When B 把成交价改成 9 元并保存
- Then 弹出一次确认并显示让价 1 元；确认后首页「今日让价」出现该行（单号、商品、数量、解析价、成交价、让价、操作人）

**AC-§2-5（P0）** 整单优惠上限
- Given 店员 B 开单，价税合计 100 元
- When B 录整单优惠 1.01 元
- Then 被拒；改成 1.00 元保存成功；管理员录 10 元成功

**AC-§2-6（P0）** audit_log 只增，且对象详情能看到变更记录
- Given 管理员改一条价格表规则
- When 保存后查看价格表详情的「变更记录」，并尝试 UPDATE / DELETE audit_log
- Then 详情出现谁、何时、前值 → 后值；数据库拒绝 UPDATE / DELETE；全站没有日志查询页

## §3 主数据与价格（9 条）

**AC-§3-1（P0）** 扁平 SKU、单位换算、整数量商品
- Given 商品「6 分弯头」，基单位「个」，包装单位「箱」= 12 个，勾选整数量
- When 开单按箱录 1，再按个录 0.5
- Then 库存按 12 个基单位入账；按个录 0.5 被拒并提示「整数量商品按整数」

**AC-§3-2（P0）** 检索排序与别名
- Given 商品编码 10086、名称「不锈钢弯头」、规格「DN20」、别名「6 分弯」
- When 搜索「10086」「DN20」「6 分弯」「弯头」
- Then 编码精确 / 前缀命中的排最前；规格词次之；名称再次；别名最后；空格分隔多词为 AND；结果 ≤ 8 条

**AC-§3-3（P0）** 停用不删，快照不受影响
- Given 一个商品已用在历史单据上
- When 停用该商品，再改它的名称与标准售价
- Then 新单不能选它；历史单据仍显示原名称、原单价；库存与报表照常出数

**AC-§3-4（P0）** 客户必挂价格表，默认表只影响新客户
- Given 系统默认价格表是「零售价」，已有客户 C 挂「批发价」
- When 管理员把默认表改成「工程价」，再新建客户 D
- Then C 仍挂「批发价」；D 自动挂「工程价」；把 C 的价格表清空保存被拒

**AC-§3-5（P0）** 规则顺序、AND 作用域与 min_qty
- Given 表内规则 1：品牌=秀辉 且 分类=阀门，公式「进价 × (1 − 2%)」；规则 2：兜底「售价 ÷ 0.87」
- When 解析一个「秀辉 + 阀门」的商品，再解析一个「秀辉 + 管件」
- Then 前者命中规则 1，后者落到兜底；规则 1 的 min_qty 按基单位比较，包装单位先换算

**AC-§3-6（P0）** 兜底唯一且最后；失败行为分层
- Given 一张价格表
- When 保存没有兜底、或有两条兜底、或兜底不排最后
- Then 三种都拒绝保存；非兜底规则公式失败（缺参考进价 / 除零 / 结果 ≤ 0）跳过并警告；兜底公式失败则整单阻断，不回退标准价

**AC-§3-7（P0）** 包装单位价格换算与舍入
- Given 基单位价 8.3333 元，包装单位「箱」= 12 个，规则舍入 2 位
- When 按箱开单
- Then 行单位价 = round(8.3333 × 12, 2) = 100.00；行含税 = round(数量 × 100.00, 2)

**AC-§3-8（P0）** 九步舍入：未税、税额残差、优惠分摊尾差
- Given 销售单 3 行，含税净额分别 10.01、10.01、10.01，税率 13%，整单优惠 0.03
- When 保存
- Then 每行未税 = round(净额 ÷ 1.13, 2)，税额 = 净额 − 未税；三行 discount_alloc 之和 = 0.03；合计区不再二次扣减

**AC-§3-9（P0）** 客户分组不参与定价；信用额度只提示
- Given 客户 C 在分组「装修队」，分组上没有任何价格配置；信用额度 5000，已欠 4800
- When 给 C 开一张 500 元的销售单
- Then 价格只按 C 的价格表解析；页顶提示「已欠 4800，本次后 5300」，但仍可保存生效

## §4 单据核心（9 条）

**AC-§4-1（P0）** 草稿不占号，丢弃不断号
- Given 新建一张销售单但不生效
- When 查看单号并丢弃草稿，再新建一张并生效
- Then 草稿单号为 null；丢弃不产生断号；生效单号是当日连续流水

**AC-§4-2（P0）** 生效取号、作废不换号
- Given 一张销售单生效，单号 XS20261124001
- When 作废它
- Then 单号仍是 XS20261124001；不回收、不复用；再开新单取 XS20261124002

**AC-§4-3（P0）** 改单到 v3：单号不变、列表只有一条、显示第 3 版
- Given 一张生效销售单
- When 连续改两次
- Then 单号不变；列表只有一条；详情显示「第 3 版」；旧版本只读、可打开

**AC-§4-4（P0）** 红冲与重开都落原业务日期
- Given 业务日期 2026-10-15 的销售单，改到 v2
- When 查看库存流水
- Then v1 的红冲行与 v2 的过账行业务日期都是 2026-10-15；净额等于按 v2 新建一张单独立过账

**AC-§4-5（P0）** 跨月改单二次确认，报表显示重放时间
- Given 上月生效的销售单
- When 本月改它
- Then 弹二次确认「会改写 YYYY-MM 的库存、毛利与往来」；确认后上月报表数值改变，页眉显示新的最近重放时间

**AC-§4-6（P0）** 作废是终态
- Given 一张已作废单据
- When 尝试改单、恢复、或复用它的单号
- Then 三个动作都被拒；只能查看与打印；要再用只能新建

**AC-§4-7（P0）** 幂等键防重复过账
- Given 一张单据已生效
- When 重复提交同一个过账请求
- Then 返回已有流水，不产生第二条；库存、往来、资金三本账都不重复

**AC-§4-8（P0）** 合计区净额不二次扣减
- Given 一张有整单优惠 5 元的销售单
- When 查看合计区
- Then 未税 + 税额 = 价税合计，且价税合计 = 各行最终含税之和；「优惠 5 元」只展示一次，不再从合计里减

**AC-§4-9（P0）** 改行单位阻断；被退货引用的行删除阻断
- Given 一张生效销售单，某行被退货单引用
- When 尝试改该行单位，或删除该行
- Then 改单位被拒（删行重加）；删行被拒并提示「先作废退货单」

## §5 单据类型（11 条）

**AC-§5-1（P0）** 销售单：价税合计 1000，本次收款 500
- Given 销售单价税合计 1000，现金 300 + 微信 200
- When 生效
- Then 本单欠款 500；客户往来余额 +500；资金账户 +500；生成一张收款单并核销本单 500

**AC-§5-2（P0）** 报价单不过账、转单锁价、过期派生
- Given 报价单 3 行，valid_to 已过
- When 打开报价单并转销售单
- Then 报价单没有任何库存 / 往来 / 资金流水；转单沿用报价单价并提示「已过期」；商品现价已变时提示差额，一键按现价重算；报价单本身不变，可再次被转

**AC-§5-3（P0）** 换货 = 退货单 + 销售单
- Given 客户拿 6 分管换 4 分管，原单已生效
- When 执行换货
- Then 一次操作生成退货单 + 销售单，两单互存 source_doc_id；库存一进一出；应收只按差价变动

**AC-§5-4（P0）** 无原单退货；退款不得超过预收
- Given 客户没有原单，直接退 3 根
- When 保存退货单并退款
- Then 无原单也能退，成本按 §6.4 兜底；退款金额超过当前预收时被拒，提示可退上限

**AC-§5-5（P0）** 采购运费到付
- Given 采购货款未税 1000，运费含税 50（9%），freight_payer = 到付
- When 生效
- Then 入库成本 = 1000 + 45.87；应付供应商 = 1000（不含运费）；生成一条 −50 的「采购运费」资金流水；不进往来、不进费用

**AC-§5-6（P0）** 采购运费代垫
- Given 同样的货款与运费，freight_payer = 代垫
- When 生效
- Then 应付供应商 = 1050；不生成运费资金流水；入库成本仍是 1045.87

**AC-§5-7（P0）** 采购退货按原入库成本
- Given 原采购行含分摊运费的未税单位成本 10.4587
- When 退 10 个
- Then 库存出库成本 = 104.59（按 4 位内部精度回冲）；应付冲减含税金额；不按当前均价

**AC-§5-8（P1）** 转账单两流水与手续费
- Given 微信转建行 2000，手续费 1
- When 生效
- Then 微信 −2001、建行 +2000；转账单显示转出 2000、手续费 1；Σ 两条流水 = −1

**AC-§5-9（P1）** 日常收支单一条流水，项目方向匹配
- Given 收支项目「房租」direction = expense
- When 用「现金」账户录一张 800 元的日常支出单
- Then 现金 −800，恰好一条资金流水；把「房租」用在日常收入单上被拒

**AC-§5-10（P1）** 盘点差异盘盈 / 盘亏
- Given 某商品账面 10 个、均价 8 元；实盘 12 个
- When 生成盘点单并生效
- Then 盘盈 2 个按 8 元入库（结存 ≤ 0 时按最后进价）；另做一张实盘 7 个的盘点单，盘亏 3 个按出库规则；盘点不进采购 / 销售成本，报表单列

**AC-§5-11（P0）** 多税率逐行汇总
- Given 一张单里 13% 商品与 9% 商品各一行
- When 查看合计区
- Then 税额按行税率快照分别算，再分组汇总；不假设整单一个税率

## §6 库存账（6 条）

**AC-§6-1（P0）** 流水之和 = 结存；卖到 0 则金额 0
- Given 任一商品的全部库存流水
- When 汇总并与 stock_balance 比对；再把结存卖到刚好 0
- Then Σqty = 结存 qty、Σamount = 结存 amount；qty = 0 时 amount = 0

**AC-§6-2（P0）** 负库存按最后进价，并进告警
- Given 结存 0，最后进价 8 元
- When 出库 5 个
- Then 成本 = 40（cost_basis = last_cost）；首页负库存角标 +1；库存查询的负库存清单出现该商品与最后一次出库单

**AC-§6-3（P0）** 跨月红冲重放，结果可复算
- Given 上月一张出库单已过账，之后又有入库
- When 跨月红冲该出库单
- Then 该商品成本链按业务日期重放，相关出库成本被改写并写 cost_recomputed_at；报表页眉显示重放时间；用同样顺序全量重算得到同一组金额

**AC-§6-4（P0）** 销售退货按原单成本
- Given 原单出库单位成本 8 元，当前均价 9 元
- When 有原单退 5 个
- Then 入库成本 = 40（cost_basis = orig_cost），不按 9 元

**AC-§6-5（P0）** 清零法与 adjust 尾差
- Given 结存 3 个、金额 100 元
- When 一次出库 3 个
- Then 出库金额取 100（清零法），结存金额 0；若重放后仍出现 qty = 0 且 amount ≠ 0，则生成一条 qty = 0、amount = −残差、cost_basis = manual 的 adjust 流水

**AC-§6-6（P0）** 期初 actual 永不重算；幂等
- Given 一张生效期初库存单
- When 后续发生任何成本重放，并重复提交该期初过账
- Then 期初流水金额不变（cost_basis = actual）；同一 posting_key 不产生第二条流水

## §7 往来账（9 条）

**AC-§7-1（P0）** 欠 1000 收 800：核销不改余额
- Given 客户欠 1000
- When 收款 800 并自动核销该单
- Then 对账单发生额 −800、期末 200、未结清单 1 张（未结 200）；往来余额 = Σ 流水 = 200；核销记录不参与余额算术

**AC-§7-2（P0）** 一收多单、一单多收
- Given 三张未结单、一张单分三次收款
- When 分别核销
- Then 一收多单生成 3 条分配；一单多收生成 3 条分配，未结依次递减；撤销其中一条分配后该单回到未结，钱回可用池

**AC-§7-3（P0）** 改小已核销的单：差额退回预收
- Given 单据 1000，已核销 1000
- When 改成 900
- Then 自动退回 100，余额 −100（预收）；二次确认写明退回金额；分配记录不删除，追加负分配

**AC-§7-4（P0）** 作废已核销的单：全额转预收
- Given 单据 1000，已核销 1000
- When 作废
- Then 余额 −1000；对账单显示预收 1000；被它结掉的分配全部释放

**AC-§7-5（P0）** 折让与坏账
- Given 应收 1000，实收 998、折让 2（抹零）
- When 保存收款单
- Then 单据结清、余额 0；对账单上折让单独可见；销售统计与毛利不变
- And 现金 0 + 折让 1000（原因 = 坏账）也能结清，资金流水 0 条

**AC-§7-6（P0）** 退货贷项冲最早未结；预收自动抵扣
- Given 客户欠 500 与一张 300 的退货单
- When 退货生效
- Then 贷项自动冲抵最早未结，余额 200；若无欠款则成为可用抵扣 300
- And 预收 500 后开单 800，自动抵扣 500，未结 300

**AC-§7-7（P0）** 对账单上下两段一致
- Given 任意区间 [from, to]
- When 生成对账单
- Then 期初 = from 之前全部流水之和；期末 = 期初 + Σ发生额；未结合计 − 可用合计 = 期末

**AC-§7-8（P0）** 账龄六桶与整笔落桶
- Given 三张单：未到期、逾期 45 天、逾期 200 天；其中一张部分核销
- When 生成账龄
- Then 三张分别落在「未到期」「31–60」「>180」；部分核销的剩余额整笔落在该单到期日所在桶；各桶合计 = 未结合计

**AC-§7-9（P0）** 预收抵扣（不改变余额口径）
- Given 客户预收 500
- When 开一张 800 的销售单并生效
- Then 自动抵扣 500，未结 300；余额从 −500 变成 +300；没有新增任何调整单

## §8 资金账（7 条）

**AC-§8-1（P0）** 收款单现金入账，折让不入资金
- Given 销售单 1000，本次收款 500 现金
- When 生效
- Then 现金账户 +500；账户余额表本期收入 +500；往来余额 +500；若改为收 800 结 1000（折让 200），资金只 +800，没有那 200 的流水

**AC-§8-2（P0）** 收款折让不产生资金流水
- Given 一张收款单含折让 200
- When 查看账户收支明细
- Then 只有现金那一条；折让不出现在资金账；往来侧单据结清

**AC-§8-3（P0）** 多账户收款拆成多条资金流水
- Given 一张收款单 1000，现金 300 + 微信 700，核销一张 1000 的销售单
- When 生效
- Then 现金 +300、微信 +700 两条资金流水；往来侧只有一笔 1000 的清账；核销分配 1 条；资金合计 = 结算行现金合计

**AC-§8-4（P0）** 期初资金落在启用日前一日
- Given 2026-01-01 启用，现金 3000、建行 12000
- When 生成期初资金单并生效
- Then 两条流水业务日期都是 2025-12-31；1 月余额表期初 15000，1 月收入不含期初

**AC-§8-5（P0）** 改收款单账户：红冲 + 重开，都落原业务日期
- Given 收款单现金 500，业务日期 2026-10-10
- When 把账户改成微信
- Then 现金 −500、微信 +500，两批流水都落 2026-10-10；往来分配不变

**AC-§8-6（P0）** 停用账户
- Given 一个有用的账户
- When 停用
- Then 历史流水照常显示；余额表仍列并标「已停用」；新单据下拉消失；旧单据改单不受影响

**AC-§8-7（P0）** 余额 = 流水和；资金流水不可改删
- Given 任一账户
- When 汇总流水、尝试 UPDATE / DELETE
- Then closing = opening + inflow − outflow = Σ amount；数据库拒绝 UPDATE / DELETE，应用层无接口；全局 Σ 账户余额 = Σ 资金流水

## §9 期初与导入（7 条）

**AC-§9-1（P0）** 期初库存入账与成本链起点
- Given 期初库存 300 根 × 8 元（未税）
- When 生效，随后卖 10 根
- Then 流水 +300 / +2400，结存 2400、均价 8；出库成本 80；期初 cost_basis = actual

**AC-§9-2（P0）** 期初单价不留空；零成本要显式勾选
- Given 商品参考进价 8.5
- When 期初单价留空；再改成 0 但不勾「零成本期初」；最后勾选
- Then 留空自动取 8.5；0 不勾选被拒；勾选后保存成功，单据与行标「零成本期初」

**AC-§9-3（P0）** 期初往来三行三日期，账龄三桶
- Given 同一客户三张欠条：2025-03-01 5000、2025-06-01 3000、2025-11-01 2000
- When 导成一张期初往来单并生效
- Then 期初余额 10000；三行流水日期 = 各自原发生日期；账龄落三个桶；收款 4000 自动结最早两张

**AC-§9-4（P0）** 启用日与早于启用日的拦截
- Given 启用日 = 2026-01-01
- When 录一张 2025-12-30 的销售单并尝试生效
- Then 生效被拒，草稿可存；启用日 = 最早生效期初单日期 + 1

**AC-§9-5（P0）** 期初日期晚于最早业务单据则拒绝
- Given 已有一张 2026-01-05 的生效业务单据
- When 建一张 2026-01-10 的期初单
- Then 拒绝生效（草稿可存）；提示期初必须早于最早业务单据

**AC-§9-6（P0）** 改期初库存触发重放
- Given 期初库存 300，已发生后续出库
- When 把期初改成 30
- Then 二次确认写明「将重算 2026-01 起成本」；保存出 v2；库存流水红冲 + 重开；报表标最近重放时间

**AC-§9-7（P0）** 导入干跑零写入；部分成功；批次可撤销
- Given 5000 行商品，第 37 行基单位为空
- When 干跑
- Then 零写入，逐行报「行号 + 列 + 原文 + 原因 + 修正建议」；修正后执行，4999 成功 1 失败（主数据部分成功）
- And 期初导入一行不合法则整批不写；同一文件再导被拦；撤销期初批次后它生成的期初单全部红冲，净额为零

## §10 报表（6 条）

**AC-§10-1（P0）** 销售毛利按未税
- Given 销售单价税合计 1130（13%），未税成本 800
- When 查销售统计
- Then 未税销售额 1000、销项税 130、毛利 200、毛利率 20%

**AC-§10-2（P0）** 退货回冲并单列退货率
- Given 本期销售 1000、退货 100（未税）
- When 查销售统计
- Then 未税销售额与成本同时回冲；退货额单列 100；退货率 = 100 ÷ 1000 = 10%

**AC-§10-3（P0）** 进货运费入成本
- Given 采购货款未税 1000，运费含税 50（9%）
- When 查进货统计
- Then 运费未税 45.87；入库成本 1045.87；到付时资金流水 −50；代垫时应付 1050、无运费流水

**AC-§10-4（P0）** 进销存汇总恒等式
- Given 任一商品任一期间
- When 查进销存汇总
- Then 每行满足「期初 + 入 − 出 = 期末」，数量与金额各算一次；期初 = 期间首日之前全部流水之和

**AC-§10-5（P0）** 呆滞清单
- Given 一个商品 90 天无出库且结存 > 0
- When 查库存统计的呆滞清单
- Then 它出现，按未税结存金额降序，显示最后出库日与呆滞天数；没有库龄列

**AC-§10-6（P0）** 资金余额表与导出过滤
- Given 任一账户、任一区间
- When 查账户余额表并与账户日记账最后一笔余额比对；再用店员账号导出 xlsx
- Then 期末 = 日记账最后一笔余额；导出的成本与毛利列被剥掉，不因为「导出」绕过

## §11 打印（7 条）

**AC-§11-1（P0）** 6 行针式一页两联
- Given 一张 6 行销售单
- When 打针式收款联
- Then 一页、两联内容一致；表头 / 明细 / 合计 / 收款明细 / 打印时间齐全；整单优惠只印一次、合计不再二次扣减

**AC-§11-2（P0）** 19 行提示改用 A4
- Given 一张 19 行销售单
- When 打针式
- Then 提示「超过 18 行，改用 A4」，不自动混纸；选 A4 后多页、表头每页重复

**AC-§11-3（P0）** 送货联无价格
- Given 销售单的送货联
- When 打印，并尝试在配置里打开价格字段
- Then 无单价 / 金额 / 收款，有签收栏；合计只有「共 N 行」；配置无法打开价格 / 收款字段

**AC-§11-4（P0）** 收款单大写金额且无核销明细
- Given 一张收款单
- When 打针式收据
- Then 大写金额正确；不印核销明细；第 2 次打印页脚出现「补打」

**AC-§11-5（P0）** 对账单上下两段一致，负数标预收
- Given 一个客户任意期间、期末为负
- When 打对账单
- Then 期初 + 发生额 = 期末；未结合计 − 可用抵扣 = 期末；期末负数标「预收 / 预付」而不印负号；多页重复表头；逾期天数正确

**AC-§11-6（P0）** 版本标识与作废水印
- Given 一张 v2 单据与一张已作废单据
- When 分别打印；再打印 v1 旧版本
- Then v2 右上印「第 2 版」；作废单印「作废」水印；旧版本印「已被第 N 版取代」灰底横幅

**AC-§11-7（P0）** 草稿禁打；计数与补打
- Given 一张草稿、一张生效单
- When 尝试打印草稿；再预览生效单两次、实际打印两次
- Then 草稿打印按钮禁用；预览不计数；实际打印 print_count = 2，第 2 次页脚带「补打」；打印人不设闸

## §12 模块与页面（3 条）

**AC-§12-1（P0）** 菜单九组、22 个路由
- Given 管理员登录
- When 展开菜单
- Then 九组：工作台、开单、收付、往来、商品、库存、资金、报表、设置；路由与 §12.2 一致（含登录共 22 个）
