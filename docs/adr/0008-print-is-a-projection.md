# 纸面是单据的投影：送货单不另立单据，模板只做展示选择

**状态**：已采纳（2026-11-24，「打印输出层」）

一张单据在纸面上可以有多种版式（收款联 / 送货联、A4 / 针式），但它们共享同一单据号、同一版本链、同一份数据。送货单不是第八类单据，而是销售单的打印版式；收款收据是收款单的纸面形态；对账单是往来账的查询结果，不是单据。

## 考虑过的方案

- **独立送货单（精斗云高级版的形态）**：可以承载线路、司机、签收照片与配送状态，但会造出第二个单号与第二份真相；1-3 人店没有配送调度，签收只是纸面的一块空白。只有将来真要做配送管理时，才值得升成独立单据。
- **逐联不同内容（客户联不印价、存根联印价）**：需要两套渲染、两次作业，两联还容易不一致；复写纸一次出两张同内容是行业默认，联次字样由预印纸承担。
- **拖拽式模板设计器**：五家厂商都有，但 1-3 人店没有维护模板的人；地图已把设计器列为 out of scope。v1 只做内置模板 + 字段 / 列序 / 列宽档 / 表尾 / logo 的轻配置。

## 后果

- 纸面内容永远从「单据版本快照 + 当前店铺档案 + 模板配置」生成；打印不写业务数据，只记 `print_count`、`last_printed_at` 与操作人。
- 一次打印作业只有一种纸型、一份内容；销售单的针式联与 A4 版是两次打印。两联靠复写纸，内容相同，联次字样由预印纸承担。
- 针式模板固定 241×93mm、内容宽 210mm、每页 6 行、最多 3 页；超过 18 行提示改用 A4，不自动混纸。A4 走流式分页，表头每页重复。
- 模板可配边界：店铺抬头、字段显隐、列顺序、列宽档、表尾文案；不可改坐标、加字段、写公式 / 条件、换字体、做设计器。行序固定按 `line_no`。
- 打印件不出现成本类字段（「权限与审计」已定），也不印实时客户累计应收；余额只在对账单上按截止日呈现。
- 送货联锁定隐藏单价 / 金额 / 收款；客户要看价就打收款联。
- 纸面标识：版本 ≥ 2 印「第 N 版」，旧版本印「已被第 N 版取代」，作废印「作废」水印；每次打印印打印时间，第 2 次起加「补打」。
- 对账单底部留客户签收栏；v1 不做独立对账函 / 盖章确认文书。
- v1 不存 PDF 归档；需要时按快照重新渲染，或用浏览器另存 PDF。
