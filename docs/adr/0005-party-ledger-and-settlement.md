# 往来是一本带符号流水，核销只决定未结分布

**状态**：已采纳（2026-11-22，「往来账、核销与对账单」）

一个客户（或供应商）一本往来账：每条业务事件落一条带符号流水，余额 = 流水之和，正整数是应收 / 应付，负数即预收 / 预付。收款、退货贷项只改变余额；把它们分配到单据上的核销记录**不改变余额**，只回答「哪张单还欠多少」。核销挂在单据身份（单号）上，不挂版本。

## 考虑过的方案

- **应收 / 预收两本账 + 独立预收款单**（星辰）：预收可定向抵扣、可单独退款；代价是多一个单据类型与一次建单动作，而「多收了几百块」是日常路径，不该变成两步。
- **不存核销表，永远按最早未结现算**：状态最少，但表达不了「这笔钱是付新单的、老单挂争议」和「这钱先押着」；账龄、对账单与改单闸门会各算各的。
- **核销也加减余额（收付款与应收各记一套）**：对账最直观，但同一笔钱有两套算术，任何一次只写一半的失败都会让余额与未结永远对不上。
- **核销挂版本**：改单后旧版本的核销失效、钱要重新分配；但客户付的是「那笔生意」，不是「那张纸」。

## 后果

- 「改小转预收、改大加应收、作废已核销全额转预收」不是三条规则，是一个恒等式的三个特例：任何单据金额变化，只需把分配额夹紧到当前金额，差额自动回到未分配池。
- 余额与未结必须同时成立：`余额 = 挂账未结 − 清账可用`。对账单上半段（滚动发生额）与下半段（未结清单据）因此天然对得上。
- 抹零、让价、坏账走收款单上的折让并必填原因，不新增调整单；折让不进销售统计与毛利。
- 退款只能是「退预收」：金额不得超过当前预收 / 预付余额；它是一条正向清账流水，不参与核销。
- 账龄只对挂账单算，按到期日（业务日期 + 账期）分桶；退货贷项与预收单独显示，不进桶。
- 对账单是查询，期初由流水现算；「已对账」只留一条极轻的对账记录，不回写单据、不冻结任何数字。
- 供应商侧完全镜像；客户与供应商是两类档案，余额不合并，不做客商匹配对账。
