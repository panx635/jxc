# 报表是账本的投影：未税成本、运费资本化、四张表只读

**状态**：已采纳（2026-11-24，「四张报表的口径」）

销售统计、进货统计、库存统计、资金统计没有自己的数据：每一格都从库存、往来、资金三本账现算，一律实时查，不建汇总表、不建缓存。账套固定为一般纳税人，成本与收入都按未税计——库存流水的金额就是未税成本，进项税另列一列，含税额只出现在采购单与应付上；毛利 = 未税销售额 − 未税销售成本。采购运费（到付为主）计入入库成本，由采购单直接落一条「采购运费」资金流水，不进往来、不进费用。

## 考虑过的方案

- **库存流水继续存含税金额，报表层再折未税**：移动加权之后结存单价是混合税率的平均，没有单一税率可折；商品税率一改，历史未税成本跟着漂。**含税与未税双口径并存**也被否掉：个体户主体不在 v1 内（见地图 Out of scope），多一列只换来解释成本。
- **采购运费走日常收支单**（「资金账与账户」当初的写法，GLOSSARY 也把运费列为它的例子）：进了成本的钱再记一次费用，将来做利润表会重复计入；且日常收支单后置，v1 会被它卡住。
- **采购运费费用化、报表在公司级扣一次**（《小企业会计准则》第六十五条第三项给批发零售业留的口子，与第十二条第一项自相矛盾）：最省，但毛利按商品、按客户都无法回答「这单到底赚多少」，而运费占货款 1–5%，不是噪声。
- **报表建汇总表 / 缓存 / 异步导出**：十年 50 万流水、5000 SKU、9000 单/年，索引聚合是毫秒到秒级；汇总表只换来「缓存与真相不一致」这一处故障面。

## 后果

- `stock_movement.amount` 记**未税**；入库另记 `input_tax`；含税额 = 两者之和。尾差清零、成本链重放、负库存估价全部跑未税这一套。
- 采购单头加「运费（含税）」「运费税率（默认 9%，无专票填 0%）」「运费承担方式（供应商代垫 / 到付账户）」；运费按行**含税金额比例**分摊，尾差记最后一行；采购退货按原行含运费的未税单位成本回冲，运费按比例退回。
- 「采购运费」成为资金流水的一类来源：由采购单生效时生成，不进往来、不进费用。ADR 0007 说的「收付款单是唯一入口」据此修订为：货品单的运费也是一类来源（与转账单、期初资金并列）。
- 日常收支单的「运费」收窄为**非采购**的物流支出（送货费、退货物流费）；采购运费不再走它。
- 报表的成本类金额（未税成本、结存金额、毛利、毛利率）按账号的「看成本」开关整列过滤；店员看得到数量与未税销售额，看不到成本与毛利。
- 跨期红冲会改写历史月毛利，报表不冻结历史，只在页眉显示「数据截至时间 + 最近一次成本重放时间」，本期间有红冲时提示「本期间数据于 YYYY-MM-DD 更正过」。
- 四张表的时间轴只有业务日期一条；退货按退货单自己的业务日期落期，成本仍取原单成本。
- 期初库存的成本单价按**未税**录入（票 2 的期初单），启用日起的四张报表因此同口径。
